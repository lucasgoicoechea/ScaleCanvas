## Observability glossary

- capacity shell: marco que representa el máximo.
- fill: volumen usado.
- pressure: ratio normalizado, no predicción.
- stale: dato existente pero vencido.
- unknown: dato ausente.
- no-capacity: existe actual pero no máximo válido.
- provider adapter: traducción de API cloud al modelo canónico.
- snapshot: vista coherente en un instante/ventana.
- hysteresis: thresholds de entrada/salida distintos.
- data plane: ingestión y consulta programática de telemetría.
- query plane: exposición read-only para consultas de IA.
- topology confidence: confianza de una relación entre recursos.
