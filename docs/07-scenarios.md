# Scenario Catalog

## Escenarios sintéticos

Internal CRUD, SaaS B2B, e-commerce estacional, banca, pipeline documental con IA, marketplace, IoT, search, app móvil y streaming metadata.

## Variantes

BASELINE, GROWTH_X2, GROWTH_X10, TRAFFIC_SPIKE, DATABASE_FAILURE, ZONE_FAILURE, BUDGET_REDUCTION, GLOBAL_EXPANSION, STRICT_LATENCY y STRICT_RPO.

## Golden tests

Cada escenario tiene JSON de entrada y expectativas parciales. Nunca comparar textos generados por IA.
