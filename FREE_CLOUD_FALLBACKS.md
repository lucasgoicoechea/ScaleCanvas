# Cuotas cloud gratuitas como respaldo

## Política

No configurar Codex, no habilitar pago y esperar el reinicio de cuota.

## GitHub Models

Acceso gratuito limitado por modelo para prototipos y revisiones.

## OpenRouter

Usar modelos cuyo ID termine en `:free`. La disponibilidad varía y la cuota sin créditos comprados es baja.

## Gemini API

Crear clave en AI Studio, revisar límites reales de la cuenta y usar solo modelos con Free Tier. Ante 429, esperar.

## Groq

Plan gratuito limitado por RPM/RPD/TPM/TPD. Revisar la consola.

## GitHub Copilot Free

Reservar autocomplete e interacciones limitadas para archivos abiertos; no usarlo como agente principal.

## Rotación

Ollama → GitHub Models → Gemini/Groq → OpenRouter free → esperar.
